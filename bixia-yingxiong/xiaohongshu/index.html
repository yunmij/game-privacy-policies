笔下英雄隐私政策

更新及生效日期：2026 年 11 月 4 日

本政策适用于开发者“开心石头人”提供的《笔下英雄》小红书小工具。游戏本身没有开发者自建的玩家数据服务器；小工具平台能力由小红书提供。

一、信息类型与用途

信息或权限用途及触发方式
游戏进度与设置在当前小工具本地保存关卡、资源、英雄成长、装备、设置及未完成的新篇。云存储内测能力获授权且客户端支持时，使用平台个人隔离空间备份和恢复同一账号的完整进度，不将两个设备的资源相加。
相册照片与视频权限仅在玩家主动点击保存迁移图片或分享图片时，调用小红书保存相册能力；首次操作可能出现系统授权提示。迁移图片在设备本地根据玩家自己的游戏存档生成，包含游戏进度，不含小红书昵称、头像或账号标识。不扫描、不读取玩家的其他照片；拒绝保存不影响正常游戏，也不删除或改动原存档。
排行榜成绩与昵称排行榜内测能力获授权时向小红书提交游戏成绩。榜单昵称由平台返回，仅用于榜单展示；游戏不自行采集或持久保存小红书资料，昵称不写入迁移图片。未授权或不支持时隐藏入口。
关注作者状态首页查询当前玩家与本小工具作者的关注状态，用于显示按钮。只有玩家点击才调用平台关注确认流程，不自动关注，不取得其他好友关系，不给予关注奖励。
玩家主动分享的图片和文本仅在使用分享功能时带入平台笔记或评论编辑器，由玩家决定编辑、发布或取消。迁移图片不会自动分享。

游戏不调用定位、摄像头、麦克风、通讯录、蓝牙，不读取剪切板，不接入自行添加的广告或统计 SDK，不通过外部网络上传游戏存档。

二、主动迁移到 TapTap

玩家可在“设置 → 导出迁移图片”查看进度并逐张保存全部图片，再在支持迁移的 TapTap 版本主动选择图片导入。图片采用游戏专用编码，不是加密文件；包含个人游戏进度，请勿公开分享。小红书端不把图片或存档直接传给 TapTap，不建立跨平台账号映射。只有玩家在 TapTap 端选图并确认后，接收端才解析并把游戏进度写入当前 TapTap 账号云存档。TapTap 端的处理见其独立 创意工坊隐私政策。

三、保存、清理与平台服务

本机缓存、文件与云存储由小红书小工具环境提供，客户端升级、卸载或清理数据可能使未同步的本机进度丢失。恢复云档前保存一份本机备份。“清空本机存档”不等于删除平台云端历史；云端与排行榜数据的查阅或删除请求可联系开发者，并按平台管理流程处理。保存相册的迁移图片由玩家自行管理，可从系统相册删除。

信息仅在实现对应功能所必要的期限内保存；小红书平台的账号、云存储、排行榜、相册权限及关注功能同时适用小红书客户端公示的隐私规则。撤回相关授权会影响对应可选功能。除玩家主动使用平台功能、取得同意或法律法规要求的情形外，不主动共享、转让或公开披露个人信息。我们采取与处理方式相适应的保护措施；停止运营或不再需要时，依法删除或匿名化处理。

四、权利与联系

玩家可在系统或小红书授权设置中管理或撤回权限，或申请查阅、复制、更正、删除相关信息。公开联系邮箱：yanmj7700@163.com，收到请求后十五个工作日内核查、处理或说明进展。小红书平台账号与平台数据问题也可同时联系小红书客服。

五、未成年人及政策更新

未成年人应在监护人指导下阅读并使用游戏，依法需要监护人同意的处理会先取得相应同意。政策更新将在本页公示；处理目的、信息类型或权利发生重要变化时，将以适当方式告知并依法征求同意。

六、本网页托管

本政策由 GitHub Pages 静态托管。GitHub 会出于安全目的记录访问者 IP，详见 GitHub 隐私声明。本页无广告、统计脚本或信息表单，无需登录。小工具不能打开站外网页时，以游戏内迁移说明及平台授权提示了解对应用途；本网页供外部查阅。
