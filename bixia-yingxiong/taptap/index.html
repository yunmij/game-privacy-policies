笔下英雄隐私政策

更新日期：2026 年 11 月 3 日 · 生效日期：2026 年 11 月 3 日

本政策适用于由开发者“开心石头人”提供的《笔下英雄》TapTap 小游戏（游戏 ID：991000；后台原名称“铅笔大战墨水怪”）。本政策说明游戏中的个人信息处理方式。涉及 TapTap 平台本身的账号、认证和平台服务时，平台还会按照其公示的隐私政策处理信息。

一、处理的信息及用途

信息类型使用目的和触发场景
昵称、头像在取得明示同意后，用于展示玩家昵称、头像和游戏身份。
好友关系、TapTap 好友列表在取得明示同意后，用于展示好友关系、好友列表和好友排行榜。
游戏成绩及进度用于保存关卡进度、英雄成长和设置，并通过 TapTap 云存档服务同步游戏进度；玩家使用排行榜时，将相应游戏成绩提交至 TapTap 排行榜服务。
玩家主动选中的迁移图片仅在玩家主动选择“从小红书迁移”并选取图片时，在设备本地读取图片中的游戏存档。图片本身不上传；玩家确认迁移后，仅将解析并校验的游戏存档同步至 TapTap 云存档。不扫描其他照片，取消选择不会改变原存档。
剪切板写入仅在玩家主动使用复制功能时写入游戏文本；本游戏不读取玩家剪切板中的原有内容。

本游戏当前代码不使用定位、麦克风录音、摄像头、通讯录或蓝牙功能，也不调用 TapTap 相册写入接口。若后续版本增加需要处理个人信息的功能，我们会先更新说明，并在适用情形下重新征得同意。

二、平台服务、本地存档与云存档

本游戏通过 TapTap 小游戏运行环境提供登录、排行榜和云存档等平台功能。相关平台信息处理规则以 TapTap 公示的隐私政策为准。本游戏不包含开发者自行接入的广告或统计 SDK。

游戏存档和设置保存在设备本地；平台云存档可用时，游戏会读取或同步当前 TapTap 账号下的游戏进度，用于备份和恢复。云存档不包含昵称、头像；头像授权信息不随迁移存档传递。玩家主动进行跨平台迁移时，游戏会先展示覆盖预览，经确认后替换进度并保存迁移记录。清除小游戏数据、更换设备或卸载相关客户端可能导致尚未同步的本地进度丢失；云存档与排行榜数据由对应 TapTap 平台服务管理。

三、信息保存与保护

除法律法规另有规定外，个人信息只在实现上述处理目的所必要的最短期限内保存。我们采取与信息处理方式相适应的保护措施，限制无关访问。停止运营或不再需要相关信息时，将依法删除或作匿名化处理；由平台保存的数据依照平台规则处理。

四、信息使用与对外提供

我们在本政策明示的用途内使用信息。超出原处理目的或合理范围时，将先告知并按要求征得同意。除经同意、实现玩家主动使用的平台功能或法律法规规定的情形外，我们不会主动将个人信息共享、转让或公开披露给第三方。

五、你的权利与联系渠道

你可以通过平台授权设置管理或撤回已授予的权限，也可以联系开发者申请查阅、复制、更正或删除个人信息，或者咨询游戏中涉及的账号处理问题。撤回授权后，相应的可选功能可能无法继续使用。

六、未成年人保护

未成年人应在监护人指导下阅读本政策并使用游戏。依法需要监护人同意的信息处理，将在取得相应同意后进行。监护人如对未成年人信息有疑问或需要删除相关信息，可以通过上述邮箱联系开发者。

七、政策更新

我们会在本页公示更新后的政策及日期。涉及处理目的、信息类型或权利的重要变化时，将通过游戏或平台中的适当方式告知，并在需要时征求新的同意。

八、本政策网页的托管

本隐私政策网页由 GitHub Pages 提供静态托管。GitHub 会出于安全目的记录和保存访问者的 IP 地址，具体规则见 GitHub 隐私声明。本网页没有加入广告、访问统计脚本或用户信息表单；浏览本页不需要登录。
